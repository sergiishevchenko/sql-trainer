# Что такое SQL

**SQL** (Structured Query Language) — язык, на котором общаются с реляционными базами данных. Данные в них хранятся в **таблицах**: каждая **строка** — одна запись (клиент, заказ, фильм), каждый **столбец** — одно свойство записи (имя, цена, дата).

SQL — **декларативный** язык: вы описываете *что* хотите получить, а СУБД сама решает *как* это сделать.

```sql
SELECT first_name, city
FROM customers;
```

Этот запрос читается почти как английская фраза: «выбери имя и город из таблицы клиентов».

## Из чего состоит запрос

| Часть | Назначение |
|-------|------------|
| `SELECT` | какие столбцы вернуть |
| `FROM` | из какой таблицы |
| `WHERE` | какие строки оставить |
| `ORDER BY` | как отсортировать |

- Ключевые слова не чувствительны к регистру: `select` и `SELECT` — одно и то же. Принято писать их заглавными.
- Запрос завершается точкой с запятой `;`.
- `*` означает «все столбцы»: `SELECT * FROM products;`

В этом тренажёре используется **SQLite** — компактная и очень распространённая СУБД. Все запросы выполняются на настоящей базе данных.
