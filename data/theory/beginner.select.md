# SELECT

`SELECT` определяет, **какие столбцы** попадут в результат и в каком порядке.

```sql
SELECT name, price
FROM products;
```

## Вычисляемые выражения

В `SELECT` можно писать не только имена столбцов, но и выражения: арифметику, функции, константы.

```sql
SELECT name, price, price * 0.9 AS sale_price
FROM products;
```

- `AS` задаёт имя столбца в результате (псевдоним).
- Арифметика: `+`, `-`, `*`, `/`, `%`. В SQLite деление двух целых — целочисленное: `7 / 2 = 3`, а `7 / 2.0 = 3.5`.
- Строки склеиваются оператором `||`: `first_name || ' ' || last_name`.
- `ROUND(x, n)` округляет до `n` знаков.

## SELECT без таблицы

SQLite позволяет вычислять выражения без `FROM`:

```sql
SELECT 2 + 2 AS answer, UPPER('sql') AS word;
```

> Совет: избегайте `SELECT *` в реальных отчётах — явный список столбцов делает запрос понятнее и устойчивее к изменениям схемы.
