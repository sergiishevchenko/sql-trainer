# FROM

`FROM` указывает **источник данных** — таблицу (а позже — соединение таблиц или подзапрос).

```sql
SELECT title, release_year
FROM movies;
```

## Псевдонимы таблиц

Таблице можно дать короткое имя и обращаться к столбцам через точку:

```sql
SELECT m.title, m.rating
FROM movies AS m;
```

Слово `AS` для таблиц необязательно: `FROM movies m`.

## Полные имена столбцов

Запись `таблица.столбец` (или `псевдоним.столбец`) однозначно указывает, откуда берётся столбец. Это станет обязательным, когда в запросе появятся несколько таблиц с одинаковыми именами столбцов (например, `id`).

## Порядок выполнения

Хотя `SELECT` пишется первым, логически СУБД сначала читает `FROM`, затем фильтрует (`WHERE`), и только потом формирует столбцы (`SELECT`) и сортирует (`ORDER BY`):

```
FROM → WHERE → GROUP BY → HAVING → SELECT → ORDER BY → LIMIT
```

Понимание этого порядка объясняет многие ошибки, например почему псевдоним из `SELECT` нельзя использовать в `WHERE`.
