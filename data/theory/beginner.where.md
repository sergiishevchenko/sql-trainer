# WHERE

`WHERE` оставляет в результате только строки, для которых условие **истинно**.

```sql
SELECT name, price
FROM products
WHERE price > 500;
```

## Операторы сравнения

| Оператор | Значение |
|----------|----------|
| `=` | равно |
| `<>` или `!=` | не равно |
| `>`, `<` | больше, меньше |
| `>=`, `<=` | больше или равно, меньше или равно |

## Строки и даты

Строковые значения пишутся в **одинарных** кавычках: `WHERE city = 'London'`. Сравнение строк в SQLite чувствительно к регистру: `'london'` не равно `'London'`.

Даты в SQLite хранятся как текст в формате `YYYY-MM-DD`, поэтому их можно сравнивать как строки:

```sql
SELECT id, order_date
FROM orders
WHERE order_date >= '2024-01-01';
```

> Двойные кавычки в SQL обозначают **имена** (столбцов, таблиц), а не строки. Пишите `'Moscow'`, а не `"Moscow"`.
