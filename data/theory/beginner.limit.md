# LIMIT и OFFSET

`LIMIT n` ограничивает результат первыми `n` строками. Почти всегда используется вместе с `ORDER BY` — иначе «первые» строки будут случайными.

```sql
SELECT name, price
FROM products
ORDER BY price DESC
LIMIT 3;
```

## Постраничный вывод

`OFFSET m` пропускает первые `m` строк. Вторая страница по 5 товаров:

```sql
SELECT id, name
FROM products
ORDER BY id
LIMIT 5 OFFSET 5;
```

SQLite поддерживает и короткую запись `LIMIT 5, 5` (сначала смещение, потом количество), но полная форма читается лучше.

## Типичная задача «top-N»

«Три самых дорогих товара», «пять последних заказов» — это `ORDER BY ... DESC LIMIT N`.

> При одинаковых значениях сортировки граница `LIMIT` может «разрезать» группу равных строк. Добавляйте дополнительный ключ сортировки, чтобы результат был однозначным.
