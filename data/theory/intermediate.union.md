# UNION

`UNION` объединяет результаты двух запросов в один набор строк и **удаляет дубликаты**.

```sql
SELECT city FROM customers
UNION
SELECT shipping_city FROM orders;
```

## Правила

1. Количество столбцов в обоих запросах должно совпадать.
2. Типы столбцов должны быть совместимы.
3. Имена столбцов результата берутся из **первого** запроса.
4. `ORDER BY` пишется один раз — в конце всего выражения — и сортирует общий результат.

```sql
SELECT first_name AS name, 'customer' AS kind FROM customers
UNION
SELECT name, 'actor' FROM actors
ORDER BY name;
```

## Метка источника

Добавленный константный столбец показывает, откуда пришла строка. Учтите: с ним одинаковые имена из разных источников уже не считаются дубликатами.

## UNION против OR

Часто `UNION` можно заменить условием `OR` в одном запросе. `UNION` нужен, когда данные берутся из **разных таблиц** или разными способами.

## Стоимость

Удаление дубликатов требует сортировки или хеширования. Если дубликатов точно нет (или они нужны), используйте `UNION ALL` — он быстрее.
